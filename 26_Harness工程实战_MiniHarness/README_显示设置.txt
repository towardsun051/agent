Harness Engineering · MarkText 宽屏阅读版
======================================

这版已经把 54 张静态流程图重新按比例缩小：
- 竖向图：最大宽度约 560 px
- 接近方形的图：最大宽度约 700 px
- 横向图：最大宽度约 850 px
- 不会放大小图，只会缩小过大的图

【推荐 MarkText 显示设置】
请打开 MarkText：Preferences -> Editor -> Text Editor

推荐值：
1. Font Size：18 px
2. Line Height：1.7（1.65~1.75 都可以）
3. Maximum Width / Editor Max Width：
   - 首选：90%
   - 如果你的版本对百分比支持不好：1100 px 或 1200 px
4. Code Font Size：15~16 px

如果你的 MarkText 版本有 Editor Width Mode：
- 优先选 Fluid（宽屏窗口）
- 如果偏好固定栏宽，则使用 Fixed + 1100~1200 px

为什么需要改 MarkText 设置：
正文 Font Size 和编辑区宽度是 MarkText 的应用级显示设置，Markdown 文件本身无法稳定覆盖；
所以这版负责把图片比例调好，而上面 4 个 MarkText 参数负责把正文变大、阅读区变宽。

使用方法：
- 保持 .md 和 assets 文件夹在同一目录结构中。
- 直接用 MarkText 打开 “Harness_Engineering_Mini_Harness_深度读书笔记_MarkText宽屏阅读版.md”。
