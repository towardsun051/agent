Hermes Agent 记忆系统 + Nudge 机制｜MarkText 宽屏静态图最终版

使用方式
========
1. 请先完整解压 ZIP。
2. 保持 Markdown 文件与 assets/ 文件夹的相对位置不变。
3. 用 MarkText 打开主 Markdown 文件。

本版格式规范
============
- 所有流程图 / 架构图均已预渲染为 PNG，不依赖 Mermaid。
- Markdown 通过 assets/diagram_xx.png 相对路径引用图片。
- 横向主图在 Markdown 中按约 850px 显示；正文仍保持宽屏阅读。
- 核心结论、条件判断、状态说明、短执行链使用统一 text 代码块，保持灰底等宽风格。
- 图中文字已放大，并避免节点重叠、裁字、箭头穿字。
- 内容组织不是聊天记录拼接，而是“整体 → 局部机制 → 数据/调用链 → 边界与纠错 → 取舍 → Takeaways”。

推荐 MarkText 阅读设置
====================
- 使用较宽的编辑区 / Fluid 宽度；正文区域约 90%，或约 1100–1200px。
- 正文阅读字号建议约 18px，行高约 1.7。
- 如果图片看起来仍偏大，可把窗口拉宽；本版已避免依赖主题 CSS 才能正常显示。

版本边界
========
- 主线严格以课程源文件为依据，课程源码口径截止 2026-05。
- 学习过程中发现的“当前主分支变化”放在附录单独标注，不会反向篡改课程主线。
