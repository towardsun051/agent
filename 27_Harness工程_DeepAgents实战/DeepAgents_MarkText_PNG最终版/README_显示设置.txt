Harness Engineering · DeepAgents · MarkText 宽屏静态图版
=================================================

本版本已将所有流程图预渲染为 PNG，不再依赖 Mermaid。

图片比例规则（沿用上一份 Mini Harness 最终宽屏版）：
- 竖向图：最大宽度约 560 px
- 接近方形的图：最大宽度约 700 px
- 横向图：最大宽度约 850 px
- 不会放大小图，只缩小过大的图
- 图中文字使用较大的字体，并在渲染后逐图检查，避免节点重叠、裁字和过小文字

【推荐 MarkText 显示设置】
Preferences -> Editor -> Text Editor
1. Font Size：18 px
2. Line Height：1.7（1.65~1.75）
3. Maximum Width / Editor Max Width：首选 90%；或 1100~1200 px
4. Code Font Size：15~16 px
5. 如果有 Editor Width Mode：优先 Fluid；固定宽度则 1100~1200 px

使用方法：
1. 完整解压 ZIP。
2. 保持 .md 与 assets/ 的相对位置不变。
3. 用 MarkText 打开 “Harness_Engineering_DeepAgents_深度读书笔记_MarkText宽屏静态图版.md”。
